# Report Cards

React + Vite + React Router. Data is stored in the browser (localStorage).

    npm install
    npm run dev

- Students look up a report card at `/` using their reg no (sample: 21CS001).
- Admin is at `/admin`. Default password is in `src/config.js`.

The admin password check runs in the browser, so it is only a simple gate.
For real use, move the data and login to a backend.
